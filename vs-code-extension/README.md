# Slingr VS Code Extension

The Slingr VS Code Extension provides IDE support for developing Slingr applications.

## Coming Soon

The VS Code extension will be integrated from the existing extension repository into this monorepo structure.

## Features (Planned)

- Syntax highlighting for Slingr models
- IntelliSense and code completion
- Integrated framework documentation
- Project templates and scaffolding
- Built-in testing and debugging support

## Installation

Install from the Visual Studio Code Marketplace:

1. Open VS Code
2. Go to Extensions (Ctrl+Shift+X)
3. Search for "Slingr"
4. Click Install

## Development

This package is part of the Slingr monorepo. See the main README for development setup instructions.

### Building the Extension

```bash
npm run build
```

### Testing

```bash
npm test
```
