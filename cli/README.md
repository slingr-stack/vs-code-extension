# Slingr CLI

The Slingr CLI tool provides command-line utilities for working with Slingr applications and the framework.

## Coming Soon

The CLI tool will be integrated from the existing CLI repository into this monorepo structure.

## Features (Planned)

- Project scaffolding and generation
- Framework development utilities
- Application deployment tools
- Model and field generators

## Installation

```bash
npm install -g @slingr/cli
```

## Usage

```bash
slingr --help
```
